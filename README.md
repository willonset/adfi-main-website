# ADFI Website

Đây là bản thiết kế trang web hiện tại của công ty của tôi: https://slimmaddy.github.io/adfi/index.html.

Từ trang này, hãy hoàn thiện thêm trang tuyển dụng cho website của công ty. Tôi muốn trang tuyển dụng có các mục:
- Bộ lọc:
+ Bộ phận (Sales, Marketing, Digital, Logistic, E-commerce, Hành chính văn phòng)
+ Hình thức (Full-time, Remote, CTV)
- Các thẻ jobs đang open (giống hình refference gửi kèm). Khi click vào, JD sẽ hiện ra với nút CTA "Apply Now". Ấn nút sẽ mở ra form điền thông tin như hình mẫu.

Trang tuyển dụng nằm trong trang web chính, đồng bộ với thiết kế của web chính.
